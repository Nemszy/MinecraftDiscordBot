## Debian / Ubuntu

```bash
sudo apt install python3 python3-pip python3-venv
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Arch

```bash
sudo pacman -S python python-pip python-virtualenv
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Fedora

```bash
sudo dnf install python3 python3-pip
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## openSUSE
